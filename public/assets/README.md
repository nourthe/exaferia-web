# Assets Directory

This directory contains assets for social media sharing and SEO.

## Open Graph Image

Place the Open Graph share image here as `vaschetti-logo-share.jpg`.

**Recommended specifications:**
- Filename: `vaschetti-logo-share.jpg`
- Dimensions: 1200x630 pixels (optimal for both Facebook and Twitter)
- Format: JPEG or PNG
- Max file size: < 5MB

The image will be used for:
- Facebook/Open Graph link previews
- Twitter Card previews
- LinkedIn share previews
- WhatsApp link previews

Current image path referenced in SEO metadata: `/assets/vaschetti-logo-share.jpg`
